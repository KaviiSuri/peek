# Peek

A lightweight, beautiful command palette for the browser.

Peek starts with one simple job: find and switch between open Chrome tabs from the keyboard. Over time, it can grow into a focused browser command surface for history, bookmarks, navigation, and small browser actions — without becoming complicated.

## Product principles

- Fast enough to feel instant
- Keyboard-first, with mouse support where natural
- Quiet, tasteful, and easy on the eyes
- Small surface area; no unnecessary settings
- Useful before it is clever

## Status

Early product discovery. No implementation yet.
