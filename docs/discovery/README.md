# Discovery archive

Wayfinding is complete. Read the [current specification](../first-release-spec.md) and [acceptance contract](../first-release-acceptance.md) before using historical material here.

- `technical/`: Chrome constraints, Poof/Effect research, search examples, presentation options and superseded acceptance drafts.
- `visual/`: visual references, images and throwaway layout/keyboard viewers.
- `planning/`: delegation briefs and historical product/map snapshots.
- [Task snapshots](../tasks/README.md): decisions and implementation tickets with recorded comments.
- [Experiments](../../experiments/): source, tests and build definitions for disposable discovery extensions. These are not the production foundation.

Historical reports can contain rejected proposals or superseded instructions. The final spec and acceptance contract take precedence. The v4 reveal-fix experiment was stopped before a fix was applied; its source is an unfinished baseline, not a delivered improvement. Dia evidence does not establish Chrome behavior; timing/rAF callbacks do not prove painted frames.

This archive excludes node_modules, nested Git repositories, generated bundles/ZIPs, raw browser/session data and transient logs. Original local artifacts remain untouched. Some historical references to local browser evidence or external repositories intentionally remain local paths; they are provenance, not portable inputs or authority to access personal browser profiles.
